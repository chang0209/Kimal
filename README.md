# 📚 만화 대사 전문 번역 앱

기획안 내용을 기반으로 제작된 기능 및 UI 검증용 프로토타입입니다.

## 주요 기능

- 🖼️ **만화 이미지 업로드**: PNG, JPG, JPEG 형식 지원
- 💬 **말풍선 자동 감지**: 이미지 내 말풍선 위치 자동 인식
- 🔤 **선택적 번역**: 전체 또는 특정 말풍선만 선택하여 번역
- 🚀 **화질 업스케일링**: Real-ESRGAN 기반 2배 업스케일링 옵션
- 💾 **결과 저장**: 번역된 이미지 다운로드 기능

## 제약 조건

- **최소 해상도**: 400x400 이상 필수
- **이미지 형식**: 단일 페이지 세로형 이미지만 지원
- **가로 세로 비율**: 가로가 세로의 1.1배 이상이면 안 됨

## 설치 및 실행

### 1. 필수 라이브러리 설치
```bash
pip install -r requirements.txt
```

### 2. Streamlit 앱 실행
```bash
streamlit run app.py
```

### 3. 브라우저에서 접속
앱이 자동으로 브라우저를 열거나, 다음 주소로 접속하세요:
```
http://localhost:8501
```

## 사용 방법

1. **좌측 사이드바**에서 만화 원서 이미지 업로드
2. 이미지 정보 확인 (해상도, 형식 검증)
3. **말풍선 선택**: 전체 또는 특정 말풍선 선택
4. **번역 시작** 버튼 클릭
5. 결과 이미지 확인 및 다운로드

## 테스트 시나리오

### ✅ 성공 케이스
- 해상도: 800x1200 이상의 세로형 이미지
- 가로 세로 비율이 정상 범위 내

### ❌ 실패 케이스 1 (저화질)
- 해상도: 300x300 이하
- 결과: "화질이 특정 수준 이하" 경고

### ❌ 실패 케이스 2 (다중 페이지)
- 가로가 세로보다 10% 이상 긴 이미지
- 결과: "다중 페이지 형식" 경고

## 기술 스택

- **Frontend**: Streamlit
- **Image Processing**: OpenCV, PIL (Pillow)
- **Numerical Computing**: NumPy
- **Language**: Python 3.8+
